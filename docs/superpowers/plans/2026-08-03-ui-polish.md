# Colossal Storage UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the 5x3 wall monitor and 51-column controller interface clean, readable, responsive, and free of number-tab input leakage.

**Architecture:** Keep rendering changes inside `app.monitor` and `app.ui`, while `app.keymap` and the UI reducer cooperate through a one-shot suppressed-character field. Extend the recording surface only enough to assert text backgrounds. No inventory, transfer, recovery, or persistence behavior changes.

**Tech Stack:** CC:Tweaked CraftOS Lua, table-driven Lua tests, Git.

## Global Constraints

- Runtime remains compatible with the target CC:Tweaked Lua environment.
- Ordinary monitor labels draw on black; only structural full-width bands and alerts use colored backgrounds.
- The compact search layout applies below 72 columns.
- Number-tab shortcuts consume only their paired character event; later numeric query input remains available.
- Every renderer remains bounds-safe after resize.
